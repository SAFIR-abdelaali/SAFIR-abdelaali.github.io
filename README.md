# Portfolio

Abdelaali Safir's portfolio, in English, French and Arabic, with dark and light themes. Built with Vite, React, TypeScript, Tailwind, GSAP and Lenis, and prerendered to static pages for GitHub Pages.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # outputs dist/
npm run preview  # serves dist/
```

Pushing to `main` deploys through GitHub Actions. In the repository settings, under Pages, the source must be set to **GitHub Actions**.
